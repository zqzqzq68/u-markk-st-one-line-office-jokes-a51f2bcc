One original one-line joke about office life, 117 characters: I asked IT to fix the printer and they sent me a ticket number, which is now the closest thing I have to a promotion. The program writes that line to `/output/entry.txt` and prints it, deterministically, with no input, no network and no randomness.

## Run it

```sh
python3 main.py
```

It validates the line against the competition gate (1–199 characters, a single line, not only whitespace), writes it to `/output/entry.txt`, reads it back to confirm the file holds exactly the joke, and prints it to stdout.
